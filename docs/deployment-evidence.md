## On-chain configuration and source

The MockUSDC runtime bytecode exactly matched the local compiled artifact and `decimals()` returned `6`. PaymentEscrow runtime bytecode exactly matched the local artifact after substitution of its immutable token address. Its `token()` returned `0xA119A6483116208EC8E8823c35566AeD782bE2bA`; `defaultAdmin()` and `owner()` returned the deployer address. `hasRole` confirmed the default admin role for deployer, `OPERATOR_ROLE` for `0x395D05661A21b679ef7d6EeA2910156AA3867aB1`, and `PAUSER_ROLE` for `0xb2a35A5368673e11294cbBf86B37A4eea91FAB44`. The admin did not hold the operator or pauser role, `paused()` was `false`, and the default admin transfer delay was `172800` seconds.

Etherscan returned `Pass - Verified` for both [MockUSDC source](https://sepolia.etherscan.io/address/0xA119A6483116208EC8E8823c35566AeD782bE2bA#code) and [PaymentEscrow source](https://sepolia.etherscan.io/address/0x9c8C9e0507f837c7F38b24EDD90B49c4842F4a17#code). A separate Etherscan API source lookup confirmed both entries, compiler `v0.8.37+commit.f401782d`, optimizer enabled, 200 runs, and constructor arguments present for PaymentEscrow. Foundry also submitted both sources to Sourcify during the Etherscan verification command.

Only the two deployment transactions were sent in this step. The later release and refund scenarios are anchored in `docs/sepolia-evidence.json`. The ignored release sidecar binds the current commit to its CI result for a fresh strict check.
